# 开发清单

## 使用规则

- 本清单是项目开发进度的唯一记录来源。
- 每次实现、调整范围或完成验收后，必须同步更新“状态”“进度”和“验收依据”。
- 进度表示已完成的可验证工作比例，不以文档、讨论或预估替代实际实现。

状态定义：`未开始`、`进行中`、`阻塞`、`已完成`、`规划中`、`暂停`。`暂停`表示用户明确暂缓该项，保留当前进度和验收证据，后续恢复时从现有进度继续。
