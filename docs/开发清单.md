# 开发清单

## 使用规则

- 本清单是项目开发进度的唯一记录来源。
- 每次实现、调整范围或完成验收后，必须同步更新“状态”“进度”和“验收依据”。
- 进度表示已完成的可验证工作比例，不以文档、讨论或预估替代实际实现。

状态定义：`未开始`、`进行中`、`阻塞`、`已完成`、`规划中`。
