# 代代桌游馆

代代桌游馆是生活模块“收藏”分类下的桌游展示工具，负责呈现馆藏卡片、玩法筛选、个人收藏状态以及桌游内容维护。卡片首部保留稳定的 `16:10` 图片展示区；用户可以在添加/编辑弹窗中选择不超过 2MB 的图片作为封面，添加、编辑和删除桌游，并通过显式保存写入馆藏。

工具使用共享 UI 组件展示馆牌、分类页签、桌游信息卡片、状态标签和保存反馈；个人收藏、桌游内容和封面仅在用户点击“保存收藏”后写入
`life.board-games.collection`，不访问其他工具的数据，也不声明文件系统、网络或其他受限能力。封面通过用户主动选择的浏览器图片控件读取，不进行任意目录访问。
